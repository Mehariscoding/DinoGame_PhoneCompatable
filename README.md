# Dinosaur Game

A browser-based dinosaur running game built with JavaScript and p5.js. The dinosaur runs automatically and you jump over obstacles to survive as long as possible. Works on both desktop and mobile.

---

## How to play

- Press **Space** to jump on desktop
- Tap the screen to jump on mobile
- Avoid the obstacles
- The game ends when you collide with one

---

## How to run it

No installation needed. Just open `index.html` in any browser and the game starts.

---

## Built with

- JavaScript
- [p5.js](https://p5js.org/) — for graphics and game loop
- p5.play — for sprite handling
- p5.sound — for audio
- HTML / CSS

---

## Features

- Mobile compatible — tap to jump
- Sound effects on jump and collision
- Animated dinosaur sprite
- Randomly generated obstacles
